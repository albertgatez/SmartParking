# SmartParking – Design Baseline

## Proyecto
SmartParking – Sistema inteligente para la gestión de estacionamientos mediante sensores, aplicación móvil, reservas y pagos digitales.

## Estado del diseño

El diseño se encuentra completo y listo para pasar a la etapa de
Construcción. Se han definido los requerimientos, arquitectura,
componentes, funcionamiento esperado, interfaces y planificación
del sistema.

La implementación del código del sistema **aún no se ha realizado
como parte de la etapa de Construcción**. El código y los avances
realizados previamente se consideran únicamente trabajo interno de
prueba y no forman parte de la Design Baseline oficial.

## Documentos recibidos
- Documento inicial: problema, antecedentes, objetivos y justificación.
- Documento de requerimientos funcionales y no funcionales.
- Análisis de factibilidad técnica, económica y de recursos.
- Generación y comparación de alternativas.
- Justificación de la alternativa seleccionada.
- Arquitectura preliminar del sistema.
- Descripción de bloques y relaciones.
- Selección de componentes y materiales.
- Modelado y resultados de simulación.
- Plan de construcción y validación.
- Cronograma de actividades.
- WBS (Work Breakdown Structure).
- Estimación preliminar de costos.
- Documento de diseño integrado.
- Prototipo y vistas de la aplicación desarrolladas en Figma.

## Restricciones conocidas
- Presupuesto limitado para la implementación del prototipo.
- Disponibilidad limitada de componentes físicos.
- Uso de sensores ultrasónicos para la primera versión del sistema.
- Dependencia de conexión a Internet para algunas funciones del sistema.
- Dependencia de servicios externos como Supabase, Stripe y Firebase.
- Compatibilidad inicial de la aplicación enfocada en Android 10 o superior.
- Tiempo de desarrollo limitado a un periodo de 10 meses.
- El sistema se desarrollará inicialmente como un prototipo académico y no como una implementación comercial completa.
