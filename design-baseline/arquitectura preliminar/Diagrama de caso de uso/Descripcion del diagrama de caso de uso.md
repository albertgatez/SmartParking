# Descripción del diagrama de caso de uso
El sistema permite al usuario interactuar con el servicio de estacionamiento de manera digital, facilitando la gestión completa desde la reserva hasta el pago y la salida. Una de las primeras funcionalidades es escanear códigos QR, lo cual le permite registrar su llegada o salida del estacionamiento de forma rápida. El usuario también puede consultar el historial de pagos, visualizando los montos y fechas de sus transacciones anteriores.

Otra función es consultar la disponibilidad de espacios, lo que le permite conocer en tiempo real los lugares libres antes de realizar una reserva. Una vez elegido el espacio, el usuario puede realizar el pago correspondiente mediante la aplicación, completando el proceso de manera segura y automatizada. 

El sistema permite al usuario reservar un espacio anticipadamente y recibir notificaciones con información relevante, como confirmaciones, tiempos de estacionamiento o recordatorios de pago. Además, el usuario puede consultar el tiempo de estacionamiento para saber cuánto tiempo lleva o le queda disponible, y si lo requiere, ampliar su tiempo de estacionamiento realizando un pago adicional directamente desde la aplicación. 

Por su parte, el sistema tiene varias funciones internas que aseguran el correcto funcionamiento del servicio. Éste se encarga de identificar los espacios disponibles, actualizando su estado en tiempo real. También obtiene el historial de pagos para mostrarlo al usuario cuando sea necesario. Durante las transacciones, el sistema procesa los pagos y registra la información de manera segura. Adicionalmente, gestiona el envío de notificaciones automáticas con actualizaciones y recordatorios, y finalmente actualiza el estado del espacio cada vez que se realiza una reserva, pago o salida, garantizando la precisión de la información.
